**https://namaz.vakit.workers.dev**

- iPhone (iOS 16.4+): bağlantıyı Safari'de açın › Paylaş › « Ana Ekrana Ekle ». Sonra ana ekrandaki Namaz simgesinden açın ve bildirimlere izin verin.

- Android'de de çalışır (Chrome). Widget için yukarıdaki APK'yı kullanın. · Marche aussi sur Android (Chrome). Pour le widget, utilisez l'APK ci-dessus.

## Kurulum (Türkçe)

1. Telefonda yukarıdaki bağlantıyı açın ve `namaz-hatirlatici.apk` dosyasını indirin.
2. İndirilen dosyayı açın. Android « bilinmeyen uygulamalar » için izin isterse: **Ayarlar › Bu kaynaktan izin ver** deyin, sonra geri dönüp **Yükle**'ye dokunun.
3. Uygulamayı açın, şehrinizi seçin ve bildirimlere izin verin.
4. Samsung'da önemli: **Ayarlar › Uygulamalar › Namaz Hatırlatıcı › Pil › Kısıtlanmamış**. Yoksa hatırlatmalar gecikebilir.
5. İsterseniz ana ekrana widget ekleyin: uygulamada **Ayarlar › Ana ekrana ekle**.

**Güncellemeler:** yeni sürüm çıkınca uygulamanın ana ekranında « Yeni sürüm hazır » yazısı ve **İndir** düğmesi görünür. Yeni sürümü eskisinin üzerine kurun: ayarlarınız ve takibiniz kaybolmaz.

## Installation (Français)

1. Sur le téléphone, ouvrez le lien ci-dessus et téléchargez `namaz-hatirlatici.apk`.
2. Ouvrez le fichier téléchargé. Si Android bloque les « applications inconnues » : **Paramètres › Autoriser depuis cette source**, puis revenez et touchez **Installer**.
3. Ouvrez l'appli, choisissez votre ville et autorisez les notifications.
4. Important sur Samsung : **Paramètres › Applications › Namaz Hatırlatıcı › Batterie › Non restreinte**, sinon les rappels peuvent être retardés.
5. Si vous voulez, ajoutez le widget à l'écran d'accueil : dans l'appli, **Réglages › Ajouter à l'écran d'accueil**.

**Mises à jour :** quand une nouvelle version sort, l'appli affiche « Nouvelle version disponible » avec un bouton **Télécharger**. Installez-la par-dessus l'ancienne : réglages et suivi sont gardés.
